B. NAT Gateway – A “Porta dos Fundos Segura”

O NAT Gateway permite que instâncias em subnets privadas acessem a internet (updates, repositórios), mas impede que a internet inicie conexões com elas.

Atenção: O NAT Gateway deve ser criado dentro de uma Subnet Pública. Se tentar criar em uma privada, ele não terá rota de saída para o Internet Gateway.

Dica de Auditoria e Custos: NAT Gateways geram custos por hora e por volume de dados processados. Sempre delete os NAT Gateways após concluir seus estudos.
Nota de Arquiteto: Em um ambiente de produção, criaríamos um NAT Gateway por AZ para evitar um Single Point of Failure (SPOF). Se a zona do NAT cair, todas as subnets privadas dependentes perdem conexão.

4. Roteamento (Route Tables)

O roteamento define o "tráfego de saída" das suas sub-redes. Sem ele, a rede estaria isolada.
