B. NAT Gateway – A “Porta dos Fundos Segura”

O NAT Gateway permite que instâncias em subnets privadas acessem a internet (updates, repositórios), mas impede que a internet inicie conexões com elas.

Atenção: O NAT Gateway deve ser criado dentro de uma Subnet Pública. Se tentar criar em uma privada, ele não terá rota de saída para o Internet Gateway.
